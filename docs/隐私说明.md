# 隐私说明

本说明用于保护未授权或不希望公开的图片。当前项目是私有专用版，角色、自拍、动作帧和图标均属于本地私有素材。

## 默认边界

- 程序不访问网络，也不上传角色图片；
- 用户照片只从本地 `user_assets/` 读取；登记原图时会保留私有原始副本并生成同分辨率 `selfie.png`；
- `user_assets/` 图片默认被 Git 忽略；
- 程序只在当前用户本地应用数据目录保存窗口位置和显示尺寸。

## 复制或分发前检查

1. 检查 `git status --ignored`，确认私人图片处于忽略状态；
2. 检查源码中不存在本机绝对路径、账号、密钥和个人信息；
3. 使用 `scripts/build.ps1` 构建私有版本，并确认这是包含私有角色素材的包；
4. 检查 `dist/OnePicDesktopPet/`，确认不包含原始真实照片或临时工作文件；
5. 如果私人图片曾经进入 Git 提交，不要只删除当前文件，应在分发前重建干净历史。
